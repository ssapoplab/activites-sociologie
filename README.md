# Activités de diffusion — Département de sociologie, UQAM

Prototype de site regroupant séminaires, ciné-socio, ateliers et colloques.

- Une activité = un dossier `activites/AAAA-MM-JJ-nom/` avec un `index.qmd` (copier `_modele/`).
- Construire : `quarto render` (le site est produit dans `docs/`).
- Publication : GitHub Pages, branche `main`, dossier `/docs`.
